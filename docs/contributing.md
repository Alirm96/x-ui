# Contributing

## How to Contribute
- Fork the repository
- Create a feature or bugfix branch
- Make your changes (see [Development Workflow](./workflow.md))
- Write or update tests
- Submit a pull request (PR) with a clear description
- Reference related issues in your PR

## Code Style
- Follow Go and Vue.js best practices
- Use descriptive variable and function names
- Keep functions small and focused
- Document complex logic with comments

## Reporting Issues
- Use GitHub Issues for bugs and feature requests
- Provide detailed steps to reproduce
- Include logs, screenshots, or configs if relevant

## Community
- Be respectful and constructive
- Review and discuss PRs
- Help others in the community
